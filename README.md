# EduGenie - Gemini Powered Learning Assistant
Part of Vetri Thiran Payirchi Thittam (Tamil Nadu Skill Development)

EduGenie is an AI learning companion built with Google Gemini API to help students learn faster...

## Features
- AI Doubt Clearing
- Smart Summarization
- Auto Quiz Generation
- Multilingual Support (Tamil & English)

## Tech Stack
Frontend: HTML/CSS/JS, Backend: Python, AI: Gemini API
